# Sistema de Controle de Estoque — Eletro Kurumin

Aplicação web desenvolvida para o gerenciamento e controle de inventário de componentes eletrônicos da **Eletro Kurumin**, permitindo o cadastro, atualização e consulta de itens em estoque com cálculo automatizado de valor patrimonial.

---

## Funcionalidades Principais

* **Autenticação de Usuários:** Acesso restrito ao sistema por meio de login com e-mail e senha.
* **Gestão de Componentes (CRUD):**
  * **Cadastrar:** Registro de novos componentes eletrônicos (nome, categoria/código, quantidade e valor unitário).
  * **Listar:** Visualização organizada de todos os itens disponíveis no inventário.
  * **Editar:** Atualização de quantidades, preços e informações cadastrais.
  * **Excluir:** Remoção de itens descontinuados ou obsoletos.
* **Relatórios de Inventário:** Geração de relatório detalhado dos componentes cadastrados, exibindo a consolidação de quantidades e o **valor total financeiro** dos itens em estoque.
